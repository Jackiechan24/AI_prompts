# 统一设计约定

网页只从 app/globals.css 加载样式。基础布局、任务成果画布与公共组件在同一入口维护，禁止通过新样式文件重复覆盖公共组件。

## 公共变量

.vitrine-site 定义文字、操作色、边框、背景、字号和圆角变量。正文17px、辅助14px；12px只用于画布内注释和页码。主文字近黑，次要文字深灰，蓝色表示操作和交互选中。

页面白底，内容区域白底细边框，成果画布白底。分类标签统一浅蓝色；状态颜色表示实际业务含义，不能与分类色混用。普通边框使用 --line。

操作按钮和内容页签为胶囊形，表单12px圆角，内容容器28px圆角，标签和筛选胶囊形。操作区域至少44px高。主操作蓝底，内容页签和两级筛选均浅蓝选中。收藏始终无背景，选中实心蓝图标。

成果图保留任务差异：PPT主幻灯片、分析主图、多表映射、会议行动、评价问题、演讲稿件、汇报结论、选题方向。每张图围绕一个主要结果组织，完整材料在详情查看。

空状态、加载、错误使用 empty 容器；表单错误仅在对应字段出现一次。顶部导航使用 aria-current，内容页签和收藏使用 aria-pressed。

字体统一使用网站本地加载的 Jiyong Sans（Noto Sans SC），不依赖设备是否安装微软雅黑。全站仅常规400与加粗700两档，SVG文字、表单及编辑器沿用同一字体。字体文件与OFL许可位于public/fonts。
