# 个人提示词与内容管理

- `/my-solutions`：我创建的、我收藏的、最近使用分开展示，列表分页。
- `/admin`：仅维护站内场景模板，每页6项。基础编辑、高级JSON、预览互相切换；正文在完整边框内滚动，预览独立滚动。个人提示词仅在“我的方案”管理。
- 新建仅需名称和正文；核心场景按需填写。支持搜索、编辑、复制、另存副本和删除。
- 详情页保存渲染后的完整正文、输入值和当时使用的模板快照；内置模板更新不覆盖个人记录。
- 个人提示词保存在 `ai-solutions:v1:personal-prompts`。只有持久写入成功才提示保存成功；损坏记录保留并沿用原有导出恢复入口。
- JSON导出包含版本及完整记录；导入检查数据、来源快照和日期。重复ID创建独立副本，不覆盖现有内容。
- 无账号与云端同步，仅当前浏览器生效。建议定期导出备份。个人提示词不会自动发布为公开场景。
