# 全场景覆盖

8个核心场景、31个二级场景均有独立方案。新增23个场景的原始编号材料和人工编写结果参考 scripts/scenario-seeds.json；实际发布配置以content/solutions各JSON为准，示例展示登记于data/scenario-presentations.json。

新增方案使用相应框架的不同模块映射；角色、步骤等适合系统提供的模块写专业预置规则，用户只填写必要任务、材料与场景变量。各模板交付结构、事实边界和验收按实际任务定义，不能以统一换标题代替。

示例包括清洗保留重复候选、25单渠道比较、格式转换保留电话前导零、明确承诺提取、未确认上线不承诺、报价6000但税费未定、资料检索保留未知、竞品未提供不等于不支持、归档保留旧版与批处理重名冲突等。

新示例按文档、代码、表格、图表、对比、行动卡、流程和文件映射呈现，避免落入旧选题示例兜底。每个案例展示原始材料、结果、同一字段生成的完整提示词和核验要点。31个场景所有方案均保持draft，尚无外部模型效果实测，不代表真实客户成果或实际执行。

新增场景需更新分类、内容、框架映射、表单顺序、释义使用说明、搜索别名及示例展示；运行内容验证、类型检查、测试、lint、build。coverage测试检查每个二级场景恰有一个方案、字段齐全、案例可渲染和状态真实。
