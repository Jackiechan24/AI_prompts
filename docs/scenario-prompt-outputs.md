# 任务专属提示词组织

其余7场景与PPT遵守同一创建原则：功能定义 → 框架模块 → 填写字段 → 适用交付 → 领域规则 → 可核对案例。统一的是完整性和创建原则，不将所有场景正文压成相同结构。

评价TRACE：任务、分类统计要求、处理动作、背景与边界、标注参考。示例不混入样本；计数、分母及优先级保留依据。

合并RISEN：职责、任务输入、按选择执行步骤、交付与约束。三种原有分支保留；仅检查分支不附带合并文件生成要求，追加不带关联键残留。

销售RISEN：职责、任务数据与口径、检查计算比较步骤、报告结果和推断边界。缺比较基础或成本不生成增长利润。

会议RTF：忠实整理职责、原文与提取任务、约定输出格式。用户指定范围优先，不强行添加排除栏目。决策承诺须有原文依据。

汇报RACE：编辑职责、任务目标与重点、对象背景材料、交付预期。复杂材料增加统一维度和证据检查，不默认制作PPT或演讲稿。

演讲CO-STAR：背景、目标、风格、语气、听众与交付。新增完整稿/提纲选择，复制时只带适用分支，案例指定完整稿。时长估计不冒充试讲。

选题CRISPE：能力职责、用户洞察与素材、目标任务、表达特点、多方向探索筛选。交付可制作的题和依据，不扩写全文或虚构流量。

所有场景的选填默认仅补充留空部分，专业规则不得改变用户事实或假称工具已执行。表单、完整案例与最终复制共同使用框架映射及模板，内容校验和专项测试覆盖分支与实例。本次仅完成结构与逻辑验证，未执行外部模型效果测试。
