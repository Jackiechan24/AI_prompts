# 框架与案例一致性复核

本轮修正三个CO-STAR案例的任务／目标重复和错误受众，替换13个通用背景，并按每个场景本身的交付要求补齐30个内容案例。PPT的网页演示对应完整逐页策划，不当作已生成独立文件。

案例现在包含主要结果及必要的字段映射、依据、计算、状态、限制、检查和后续安排，全部在成果页签展示。data/case-contracts.json将框架模块、输入字段和实际交付章节一一登记。它是可复查的参考合同，不是模型评测报告。

具体修正：营销受众为移动办公人群，目标为产品能力理解；邮件受众为客户且不新增回访承诺；内容受众为新人且目标是三问的使用。JSON转换明确字段、类型、缺失null和完整数组；图表补选型与刻度；报价补税费付款有效期与审批；项目补关键结果、资源风险验收与首版反馈；归档补冲突和回退。

31个框架选择有任务专属理由。框架不是效果保证，也不是一类任务唯一选择。小样本行业研究案例明确是资料简报与证据边界案例，不替代完整行业调查；成品制作、联网检索、文件移动等能力仅在实际执行后才记为完成。

自动验证覆盖字段与模块、案例模板渲染、交付章节列数、受众目标不再通用填充、JSON可解析、关键数值和draft状态。外部模型正常、缺失、异常及边界测试仍待执行；不改testedAt、qualityStatus或validationRecords以制造已验证印象。
