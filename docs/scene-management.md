# 场景分类与提示词管理

导航统一为“提示词、场景分类、我的提示词、提示词管理”。首页标题与说明、搜索和快捷入口居中。

提示词管理提供两项工作区：
- 提示词列表：新增只填名称、场景、正文；之后可继续补充填写变量和成果案例。新增始终为未实测草稿，不复用其他案例事实。
- 场景管理：新增核心类别及二级场景、重命名、上下排序、调整二级场景所属类别。相关提示词归属同步更新。

目录保存在 `ai-solutions:v1:scene-catalog`，类别使用稳定slug，场景归属以提示词ID映射。首页筛选、场景分类、管理选择器读取同一目录。仅当前浏览器生效，可导出目录设置；没有自动发布到代码仓库或其他设备。

个人保存的提示词继续独立保存在“我的提示词”，不与场景模板混用。
