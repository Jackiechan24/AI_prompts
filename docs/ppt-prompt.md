# PPT提示词与填写配置

PPT使用CO-STAR：C映射task/materials/thinking，O映射objective，S映射visual，T映射tone，A映射audience，R映射mode/length/delivery/file_specs。主题与目标不再混填。

五项必填：主题场合、可用材料、主要目标、受众使用方式、交付范围。材料可注明仅有主题，复制只做结构校验，不判断业务输入是否合理。其他字段按需填写，默认配置仅补充未指定部分。

三种mode各自拥有完整模板：仅大纲、完整逐页策划、成品制作。前两种隐藏file_specs，复制也不包含旧文件规格。成品缺省16:9 PPTX可编辑；用户指定HTML等格式优先。未指定页数根据任务建议，不固定8页。

每个分支均包含CO-STAR对应内容、明确交付与专业处理要求；成品分支才增加文件规格、可编辑范围、实际检查与工具限制。所有分支保留材料冲突、事实来源、篇幅取舍和关键缺口处理规则。

案例保留6页10分钟零售复盘，使用同一分支选择和模板渲染，指定独立HTML网页，数据S1/S2与既有展示一致。本次改动并非外部模型效果实测。

测试只运行tests目录，避免releases中的历史测试混用当前别名。专项检查覆盖三分支、隐藏字段残留、必填目标、默认与自定义、案例一致性。
